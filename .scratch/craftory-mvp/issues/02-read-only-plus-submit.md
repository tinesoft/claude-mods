# Read-only plus submit

Type: grilling
Status: resolved

## Question

Does the mod only show the frontier and submit `/wayfinder`, or also edit map and ticket files?

## Answer

Read-only plus submit. `/wayfinder` already claims, resolves and updates the map, so a second writer would conflict and break the principle that Matt's skills do the work. The mod shows the frontier and claimed tickets and submits `/wayfinder <map>` (next ticket, or a named one).
